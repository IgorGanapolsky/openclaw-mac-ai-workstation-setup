### Summary

On macOS, native Computer Use was asked to open a new Google Chrome window and type a complete HTTPS URL. The tool call contained the correct URL, but the subsequent accessibility readback showed a Google search for `://c.ccl.c.z`.

The requested URL had 28 ASCII characters; the received fragment had 12. The fragment is a subsequence of the original URL in the original order, consistent with character loss rather than a different URL being generated by the agent.

This report documents **one confirmed failure in the retained session logs**, observed on November 8, 2026. It is not a deterministic reproduction or a fresh test. The internal cause is unknown.
